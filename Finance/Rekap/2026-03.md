# 📊 Rekap Maret 2026

---

## 💰 Pemasukan

```dataview
TABLE kategori AS Kategori, nama AS Nama, number(jumlah) AS Jumlah
FROM "Finance/Daily"
WHERE contains(type, "pemasukan") AND file.day >= date(2026-03-01) AND file.day < date(2026-04-01)
SORT file.day DESC
```

---

## 💸 Pengeluaran

```dataview
TABLE kategori AS Kategori, nama AS Nama, number(jumlah) AS Jumlah
FROM "Finance/Daily"
WHERE contains(type, "pengeluaran") AND file.day >= date(2026-03-01) AND file.day < date(2026-04-01)
SORT file.day DESC
```

---

## 🏷️ per Kategori

```dataview
TABLE sum(number(jumlah)) AS Total
FROM "Finance/Daily"
WHERE contains(type, "pengeluaran") AND file.day >= date(2026-03-01) AND file.day < date(2026-04-01)
GROUP BY kategori AS Kategori
SORT sum(number(jumlah)) DESC
```
